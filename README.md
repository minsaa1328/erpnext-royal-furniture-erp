# ERPNext Business Management System

An enterprise ERP solution developed using ERPNext 16 and the
Frappe Framework for a manufacturing business scenario.

## Overview

This project demonstrates the configuration and customization of
ERPNext to support integrated business processes across sales,
purchasing, inventory, and accounting.

## Key Contributions

- Configured ERPNext 16 using the Frappe Framework on Ubuntu.
- Configured integrated sales, purchasing, inventory, stock movement,
  and accounting workflows.
- Customized ERPNext functionality using Python and JavaScript,
  including DocTypes, forms, workflows, business logic, and
  validation rules.

## Technologies

- ERPNext 16
- Frappe Framework
- Python
- JavaScript
- MariaDB
- Ubuntu

## Business Processes

### Sales

Quotation → Sales Order → Delivery Note → Sales Invoice

### Purchasing

Purchase Order → Purchase Receipt → Inventory Update
